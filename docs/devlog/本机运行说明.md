## 再次启动

先打开 Docker Desktop，待引擎就绪，在工作区根目录执行：

```powershell
./scripts/start-dev.ps1
```

脚本启动三个数据库，保留已经监听的应用端口，再在后台启动缺少的前后端服务。后端通常需要约 15 秒；若端口被其他程序占用，需先辨认程序。日志位于 `.local/backend-stdout.log`、`.local/backend-stderr.log` 和前端对应日志。首次启动的前端仍在原终端中运行，其日志不在新文件里。

需要前台观察输出时，分别使用 `scripts/start-backend.ps1`、`scripts/start-frontend.ps1`。默认 Java 路径为本机 `D:/PyCharm 2025.1/jbr`，可以给后端脚本传 `-JavaHome` 指定其他兼容 JDK。没有修改系统默认 Java 26。

本机私有配置为 `.local/runtime.env`，公开字段示例见 `deploy/runtime.env.example`。数据库密码和模型密钥只保存在本机私有配置及本机数据库中；发布代码、打包课程材料时排除 `.local`、数据库卷和日志。当前模型配置已通过应用接口写入本机 `ai_properties`，只改环境变量不会自动更新已有模型记录。

停止数据库可以执行以下命令，保留已有数据卷：

```powershell
docker compose --env-file .local/runtime.env -f deploy/compose.local.yml stop
```
