## 2026-10-20 题库 RAG（知识检索智能体第一阶段）

新增 `interview/questionbank` 模块与出题检索增强，属三智能体方案中"知识检索智能体"的第一阶段落地；岗位情报（联网搜索）与数据分析（MySQL 工具）智能体尚未实施。

1. 新增 MySQL `question_bank` 表（`admin/src/main/resources/sql/question_bank.sql`）与 15 道 Java 后端种子真题（含参考答案与评分要点 JSON），已导入本机库。
2. 新增题库 CRUD：`QuestionBankController/Service/Mapper/Entity` 与分页、启停、逻辑删除接口；全部经 MyBatis-Plus 预编译参数绑定，无拼接 SQL。检索测试、重建索引、按方向统计接口一并提供。
3. 引入 LangChain4j 1.14.1（BOM）+ `langchain4j-community-dashscope`/`langchain4j-community-redis` 1.14.1-beta24：千问 `text-embedding-v3`（1024 维）向量 + Redis Stack 向量索引。RAG 默认关闭，经 `XUNZHI_QUESTION_BANK_RAG_ENABLED` 开启；密钥走 `.local/runtime.env` 的 `DASHSCOPE_API_KEY`。
4. `QuestionBankRagService`：题目向量化入库/删除/全量重建/语义检索；所有向量链路异常仅告警并降级为空结果，不阻断 CRUD 与出题主流程。
5. `DirectInterviewAi` 出题角色接入检索增强：出题前用简历文本（截断 6000 字）检索 top-8 真题注入提示，要求模型改编而非照抄，输出新增 `source_ids` 溯源数组（存在时校验为数组，不强制等长以免出题失败）。
6. 本地 Compose Redis 由 `redis:7.2` 换为 `redis/redis-stack-server:7.2.0-v10`（RediSearch 向量检索所需），沿用原数据卷与 16379 端口，旧键保留。
7. 依赖兼容修复（命令行 JDK 26 编译环境）：Lombok 1.18.32→1.18.48；Mockito 5.14.2→5.24.0；显式管理 byte-buddy 1.18.15 与 Jedis 7.2.1（`langchain4j-community-redis` 按 Jedis 7 编译，Spring Boot BOM 原解析为 5.x 导致运行时 `NoSuchMethodError`）；`RedisEmbeddingStore` 需声明 `metadataKeys`，否则检索回读报 `Cannot parse null string`。`DirectInterviewAiTest` 构造调用同步新增 RAG mock 参数并补 `ragServiceMock()`。

验证：7 个测试类 17 项通过；本机实测重建索引 15 条、语义检索（"HashMap 红黑树"→id1/0.809）、上传简历 RAG 出题 3 题（responseTime 3148ms），原始响应含 `source_ids:[null,14,null]`，第 2 题确认改编自题库 id=14。证据存 `.local/rag-question-evidence.json`（不含令牌与密钥）。检索排序质量（个别语义近似查询 top3 偏移）与前端题库页面接线待后续处理。
