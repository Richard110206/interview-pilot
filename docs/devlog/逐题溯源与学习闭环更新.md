# 逐题溯源、评分与学习闭环

更新日期：2026-10-22。保留映答现有蓝紫视觉体系，本次自主改动覆盖 Java 直连面试流程、报告、学习工作台与资源加载。沿用 AI-Meeting / XunZhi 二次开发基座及原许可证，未修改教师基准文件。

## 使用入口

- 报告下方“从这道题，回到它的依据”：查看逐题原题、参考答案、评分要点、知识片段、文档与 PDF 页码；收藏或直接进入对应专项练习。
- 侧栏“我的练习”：待巩固、错题、收藏、全部题目；查看上次回答与反馈、提交新回答、查看练习记录。
- 题库每题可“收藏练习”，无需先完成整场面试。
- 报告“查看本场任务交接与工具执行”展开真实执行轨迹。

## 评分与历史兼容

`text-v1` 使用准确性 40%、完整性 30%、推理 20%、表达 10%。模型必须返回四项 0–100 分，Java 校验并按权重计算总分，不直接信任模型总分；跑题时各项至多 20 分。评分温度 0.1。

回答分为已成功提交主问题的平均分，追问不重复计入。综合分为简历分 20% + 回答分 80%；缺少简历分时使用回答分。未提交任何主问题回答时回答分、综合分为空，不计作 0。雷达只汇总实际保存的维度，并展示覆盖题数。旧报告缺失维度和来源时明确提示，不补造。

错题为最新得分低于 60，待巩固为低于 75。再练习更新学习工作台的最新成绩，不改写原场次报告。新答案使用新的请求标识；失败后相同答案重试复用标识，防止重复计分和重复存储。

跨场次展示最近 20 场，比较已作答主问题均分；差值仅在同方向、同评分版本之间计算。岗位、题目难度仍会影响可比性。列表最多显示最近 200 道学习题目，报告深链可打开对应旧题。

## 逐题证据与存储

题目只允许引用本次实际召回的题库 ID、知识块 ID，保存来源内容快照，后续编辑资料不会改变历史依据。追问沿用父题参考资料并标明继承关系。MySQL 保留账号、题库、知识块、面试主记录；新增业务数据在本机 MongoDB，执行轨迹同时使用 Redis 缓存与 MongoDB 持久化。

新增集合：`interview_question_evidence`、`interview_assessment`、`interview_study_item`、`interview_practice_attempt`、`interview_learning_summary`、`interview_execution_event`。接口先检查当前用户与会话/条目归属。评分报告只使用成功接受的提交记录。

新 PDF 按实际页面切分并保存 `page_start/page_end`，页码为 PDF 文件页序，不保证与印刷页码相同。现有库共 2930 块，通过实际原文件唯一、有序文本锚点恢复 2237 块页码；其余保持未知。新环境先执行 `learning-pages-migration.sql`，新建库定义同步包含这两个可空字段。已有本机数据库已迁移。

## 任务交接与工具选择

简历分析独立调用模型，提取事实、岗位与检索词，并从 `question_bank` / `knowledge` 白名单选择检索工具。服务端执行工具后，把结构化事实与实际结果交给出题阶段；作答进入评分阶段，后续追问继续受原面试规则约束。无效分析有明确降级路径。

界面展示真实分析、召回、出题、评分及追问事件和耗时。持久化轨迹不包含简历、回答正文或模型内部思维过程。不是可以任意执行工具的自治系统。

## API

以下相对 `/api/xunzhi/v1`，全部要求登录：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/interview/sessions/{sessionId}/insights` | 来源、维度、汇总口径 |
| GET | `/interview/learning/items?filter=weak` | weak / wrong / favorite / all |
| GET | `/interview/learning/items/{id}` | 单题学习详情 |
| PUT | `/interview/learning/items/{id}/favorite` | 收藏切换 |
| POST | `/interview/learning/question-bank/{bankId}/favorite` | 从题库加入收藏 |
| GET / POST | `/interview/learning/items/{id}/attempts` | 练习历史 / 提交答案 |
| GET | `/interview/learning/history` | 最近场次比较 |

## 字体与图片

MiSans 使用互斥 unicode-range 分成界面、常用文字、少见字后备，完整字体保留。实际浏览器冷加载：首页字体及字体 CSS 约 0.57 MB，包含动态题目的学习页约 3.21 MB；两页均未请求完整 11.9 MB 字体，实际字体为 MiSans VF。少见字仍可能触发完整文件。

两张白描装饰改用 WebP，合计 365386 字节，原 PNG 保留为设计源。报告与学习页增加加载、失败重试、无题、无评分提示，移动端比较表在容器内横向滚动。
