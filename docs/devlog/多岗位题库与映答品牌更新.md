## 审查与功能调整

- 入库前检查题干、答案、评分要点、出处页码和同文重复；归并过细技能标签，使每个新岗位保留少量可浏览的技能分组。
- 审查并修正 16 条候选中的过时前提或答案细节，包括 constexpr、后置++返回类型、多态析构、Go panic/recover 与循环变量语义、LayerNorm 的归一化维度、模型评估与样本去重。
- 资料校核参考：[PyTorch LayerNorm](https://docs.pytorch.org/docs/main/generated/torch.nn.LayerNorm.html)、[Hugging Face tokenization](https://huggingface.co/docs/transformers/main/tokenizer_summary)、[原始 BERT 仓库](https://github.com/google-research/bert)、[scikit-learn 评估指标](https://scikit-learn.org/stable/modules/model_evaluation.html)、[MDN DOMContentLoaded](https://developer.mozilla.org/en-US/docs/Web/API/Document/DOMContentLoaded_event)。未将资料中的陈旧实现细节无条件当成最新语言保证。
- 题库页增加岗位筛选，技能数量由后端按当前岗位聚合查询；语义检索限定展示当前岗位的召回结果。参考答案展开后展示评分要点与来源。
- 联网扩充入口可指定岗位；后端出题提示从固定 Java 编审改为按指定岗位编审。
- 并行导入发现 `PdfKnowledgeSplitter` 用共享 `lastPageCount` 保存单次调用状态，导致 C++篇页数被写成另一个文档的278页。已改为局部不可变提取结果，并修正 C++文档为105页。新增测试以同一个切分器并发处理64次不同页数PDF，断言页数与内容保持对应。

- 整理技能标签时发现旧向量写入使用随机文档 ID，但删除按题库 ID，导致编辑时追加重复向量。已改为通过 `addAll(ids, embeddings, segments)` 显式使用题库 ID，重建清理旧随机向量，并实测相同题目再次保存不会增加索引文档数。新增稳定 ID 与禁用移除回归测试。
