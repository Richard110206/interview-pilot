# 混合面试与界面改版（2026-10-21）

用户需求：题库参与面试，在项目经历中穿插技术八股；改进整体配色、字体、首页动效、留白与按钮布局。

## 业务变化

- `DirectInterviewAi` 为每场生成明确的题型序列，默认三题依次为【项目深挖】【八股原理】【场景应用】，题数变化时循环安排。题目由模型根据简历和检索材料生成，具体内容仍受模型生成影响。
- 原有简历阶段的题库／知识库双源检索保留；评分与追问阶段新增按当前问题和回答重新检索。向量服务故障仍降级到原有模型链路。
- 题库页面提供混合面试入口，面试入口和面试室说明与此一致。
- 真实验证使用独立合成测试账号和既有合成 PDF，已生成三类题，提交一次作答并得到评分和追问，随后结束测试会话。没有把合成测试表现写成用户真实能力。
- 证据：`.local/mixed-interview-evidence.json`。这次短场验证不替代此前完整面试／报告回归验证。

## 视觉变化

- 共用蓝紫主色、浅蓝底色、深蓝正文，侧栏选中态、按钮、表单、题库、知识库、面试室与报告共用令牌。
- 首页以交互式面试对话作为主视觉，支持切换三个环节、键盘导航、暂停波形动画；减少动态效果偏好下关闭动画。
- 本地字体为 Noto Sans SC 和 Noto Serif SC 的 WOFF2 子集，分别承担正文和首页标题。资源来自本机同名字体，不依赖运行时外网。OFL 全文及字体原始版权在 `public/fonts`；字体源项目： https://github.com/notofonts/noto-cjk 。新界面用名 Interview Sans／Interview Serif。
- 真实系统录屏保留，增加从录屏抽出的海报帧；录屏展示的是此前版本的界面，不作为此次改版的最新页面证明。
- 面试入口改用练习示例与准备清单；题库合并重复的主操作。聊天空白页增加可编辑的技术讨论起点，点击只填入输入框，不自动发送。

## 设计选择

使用本机 taste-skill、frontend-design 和 ui-ux-pro-max。核心概念：将简历与题库的技术考点编排成面试排练脚本。首页草案采用 taste-skill 的 borrowed-category（排练空间）方向；主色和字体依据用户提出的明确视觉修正选择。

自动视觉检查在 1440／1024／390 像素下运行。允许 `few-pictures`（软件界面与真实录屏足以说明产品，无需填充无关照片）和 `focal-point`（保留标题／可操作面试预览双重点，避免过大的装饰标题挤占内容）。首页预览用 data-ui 标识实际界面片段。自动检查的页面高度测量不理解应用内滚动容器，因此还用 Playwright 实测页面、交互和溢出。
