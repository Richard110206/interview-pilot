# 字体、执行过程与演示视频更新

2026-10-22。本轮保留映答蓝紫浅蓝视觉方向，完成以下更新。

## 字体与界面

原正文字体仅包含固定文案中的字符，题库、模型回答等动态中文会回退到系统字体。现在 `interview-sans.woff2` 使用完整 Noto Sans SC 可变字体（约 7.8 MB），Tailwind 正文及输入框、按钮使用同一字体。首页衬线大标题作为品牌字体保留。统一追问、评分卡片中的旧绿色、黄色和灰褐色；修正雷达图标签边界。完整中文字体优先解决显示一致性，首次下载比原子集大。

## 本场思路

面试室增加四阶段连线：读简历 → 找依据 → 提问题 → 看回答。显示实际题库召回数、知识片段数、当前执行步骤，并可展开真实工具名称、耗时和引用编号。

Java 服务在 PDF 提取、双源检索、出题、评分、追问周围记录执行事实。会话归属校验后才允许读取，Redis 最多保留 150 条事件、一天过期。记录不包含简历正文、问答正文、提示词或模型内部推理。可视化描述现有执行流程，后续显式多智能体状态图仍按项目方向推进。

## 演示视频

参考用户指定项目集的 Remotion 飞入动画，用映答品牌资产制作 7 秒片头，添加原创合成音效。实际浏览器录制题库筛选与检索、知识检索、用户授权 PDF 简历上传、项目提问、示范作答、评分追问、执行轨迹和报告复盘。总长 63.063 秒，1080p，已替换首页视频及封面。

录制使用隔离浏览器；剪辑观察、时间线验证、合成和 QC 使用本机 video-agent-kit 官方 CLI。详见 `demo-video/README.md`。演示回答由脚本填写，分数和反馈为真实系统返回，不能用作用户实际能力评价。
