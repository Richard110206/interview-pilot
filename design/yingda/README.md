# 映答：名称与视觉素材

“映”是照见和反馈，“答”是技术表达与面试回答。用于多岗位面试练习，沿用现有蓝紫与浅蓝配色。

本轮使用内置 ImageGen 工具生成 3 张素材，提示词和透明背景参数保存在 [imagegen-prompts.json](imagegen-prompts.json)。没有使用 CLI 图像生成回退。

- Logo 原稿：[originals/logo.png](originals/logo.png)；部署资源：`project/frontend/public/brand/yingda-mark.png`、`yingda-mark-256.png`、`yingda-mark-64.png`、`yingda-mark-32.png`。带真实 alpha 透明通道。
- 多岗位练习插图：[originals/careers.png](originals/careers.png)；部署资源：`project/frontend/public/brand/careers.webp`。用于首页多岗位介绍和登录页。
- 知识路径插图：[originals/knowledge.png](originals/knowledge.png)；部署资源：`project/frontend/public/brand/knowledge.webp`。用于题库页头和知识库内容区。

原始 PNG 保存在本项目内；WebP 压缩及图标尺寸转换用于前端加载，未另行改绘内容。旧开源项目署名与许可证保留，产品显示名称、侧栏／聊天／首页 logo 和 favicon 已切换。
